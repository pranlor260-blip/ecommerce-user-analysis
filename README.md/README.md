# 电商用户经营与销售达成分析

基于 1200 名用户、7000 笔订单及 365 天销售目标数据，使用 SQL、Python、Power BI 完成数据清洗、多表关联、经营分析，输出交互式看板。

## 数据说明

| 表 | 行数 | 说明 |
|---|---|---|
| users | 1200 | 用户画像 |
| products | 60 | 商品信息 |
| orders | 7000 | 订单明细 |
| daily_targets | 365 | 日销售目标 |

时间范围：2025-01-01 至 2025-12-31。

## 分析流程

1. 数据清洗：SQL 多表关联 + Python pandas，统一渠道与城市口径，衍生月份、客单价等字段
2. 指标体系：搭建销售、用户、商品渠道三大维度，定义核心指标 20+
3. 业务分析：销售趋势、目标达成、品类渠道、退款分析、RFM 用户分层
4. 可视化：Power BI 搭建 2 页交互式看板

## 核心发现

- 净收入最高月：5 月（86,840 元）
- 目标达成率最低月：4 月（12.20%）
- 直播渠道客单价最高（138.49）
- 洁面退款率最高（8.87%）且客单价最低（85.24）
- 高价值用户 302 人（占 25.25%），贡献 38.01% 消费
