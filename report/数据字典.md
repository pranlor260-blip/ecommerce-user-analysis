| 字段 | 含义 | 类型 | 备注 |

| 字段 | 含义 | 类型 | 备注 |

| net_amount | 净收入 | float | 退款/取消为 0 |
| is_refund | 是否退款 | int | 0/1 |

### daily_targets（日目标表，365 行）

| 字段 | 含义 | 类型 | 备注 |

## 二、清洗说明

### 2.1 清洗的问题

| 问题 | 位置 | 处理方式 |
|---|---|---|
| 渠道大小写不一致（APP / app） | orders.channel | 去空格 + 统一大写 |
| 渠道有隐藏空格（“ 小程序”） | orders.channel | `.str.strip()` 去除 |
| 城市带“市”字（上海市/成都市） | users.city | 去除“市”字 |
| 日期是字符串 | orders.order_date / users.register_date | 转 datetime |

### 2.2 衍生字段

| 字段 | 含义 | 计算方式 |
|---|---|---|
| year | 年份 | order_date.dt.year |
| month | 月份 | order_date.dt.month |
| quarter | 季度 | order_date.dt.quarter |
| weekday | 星期几 | order_date.dt.dayofweek（0=周一） |
| is_valid | 是否有效订单 | order_status == '已完成' → 1，否则 0 |

### 2.3 清洗后渠道

只有 4 个：`APP`、`PC`、`小程序`、`直播`

### 2.4 清洗后城市

28 个，全部无“市”字、无空格。

## 四、关键口径说明

| 指标 | 口径 |
|---|---|
| GMV | `SUM(amount)`，含取消/退款订单（下单口径） |
| 净收入 | `SUM(net_amount)`，退款/取消为 0 |
| 有效订单 | `order_status = '已完成'` |
| 退款率 | `已退款订单数 / 总订单数` |
| 取消率 | `已取消订单数 / 总订单数` |
| 客单价 | `SUM(net_amount) / COUNT(DISTINCT order_id)`（有效订单口径） |
| 目标达成率 | `当日净收入 / 当日target_revenue` |
