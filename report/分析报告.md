# 电商用户经营与销售达成分析报告

## 一、项目背景

基于某电商平台 2025 年全年数据，分析用户经营与销售达成情况，定位业务问题，输出优化建议。

数据规模：1200 名用户、7000 笔订单、365 天销售目标。

## 二、数据说明

| 表 | 行数 | 说明 |
|---|---|---|
| users | 1200 | 用户画像 |
| products | 60 | 商品信息 |
| orders | 7000 | 订单明细 |
| daily_targets | 365 | 日销售目标 |

数据覆盖时间：2025-01-01 至 2025-12-31。

## 三、分析方法

1. **数据清洗**：使用 SQL 多表关联 + Python pandas，统一渠道大小写、去除城市“市”字、处理支付方式隐藏空格，衍生月份、季度、客单价等字段。
2. **指标体系**：搭建销售、用户、商品渠道三大维度指标体系，定义 GMV、净收入、目标达成率、退款率、复购率等核心指标 20+。
3. **多维分析**：完成销售趋势、目标达成、品类渠道、退款、RFM 用户分层、用户画像与复购分析。
4. **可视化**：使用 Python/Matplotlib 和 Power BI 完成图表与看板。

## 四、核心发现

### 1. 整体经营

- GMV：1,080,149 元
- 净收入：940,201 元
- 客单价：134.31 元
- 退款率：7.66%，取消率：5.19%

### 2. 销售趋势

- 净收入最高月：5 月（86,840 元）
- 净收入最低月：11 月（71,272 元）
- 全年平均目标达成率：15.37%

### 3. 目标达成

- 达成率最低月：4 月（12.20%）
- 达成率最高月：10 月（18.95%）
- 下半年达成率整体高于上半年

### 4. 渠道表现

| 渠道 | 净收入 | 客单价 |
|---|---|---|
| APP | 389,693 | 134.56 |
| 小程序 | 254,827 | 131.42 |
| PC | 177,137 | 135.32 |
| 直播 | 118,544 | **138.49** |

**直播客单价最高，APP 净收入最高。**

### 5. 品类表现

| 品类 | 净收入 | 客单价 | 退款率 |
|---|---|---|---|
| 面膜 | 180,274 | **155.01** | 7.22% |
| 面霜 | 173,117 | 143.31 | 7.45% |
| 洗发水 | 170,218 | 146.11 | 7.47% |
| 精华 | 161,193 | 143.54 | 7.30% |
| 防晒 | 159,248 | 131.28 | 7.67% |
| 洁面 | 96,152 | **85.24** | **8.87%** |

**面膜双高，洁面双低且退款率最高。**

### 6. 用户分层（RFM）

- 总用户：1196
- 重要价值用户：197 人（16.47%），贡献 28.30%
- 高价值用户：302 人（25.25%），贡献 38.01%
- 一般挽留用户：412 人（34.45%），消费贡献 18.78%

### 7. 用户画像

- 女性 53.42%，男性 46.58%
- 25 岁以下最多（317 人）
- 华东地区最多（290 人）
- 城市 Top3：杭州、苏州、上海

## 五、业务建议

1. **加大直播投入**：直播客单价最高（138.49），建议增加直播场次，提升高客单价商品曝光。
2. **优化洁面品类**：洁面客单价最低（85.24）且退款率最高（8.87%），建议优化选品或调整定价策略。
3. **重点运营高价值用户**：302 人贡献 38.01% 消费，建议建立专属权益体系，提升复购。
4. **激活一般挽留用户**：412 人占 34.45%，但消费贡献仅 18.78%，建议通过优惠券、召回活动激活。
5. **调整目标设定**：4 月达成率最低（12.20%），建议结合历史数据优化目标，避免目标过高。
